# YouTube Code Examples

This repository contains code examples from my YouTube videos. Each folder corresponds to a specific video tutorial or demonstration.

## Structure

Each folder is a self-contained project that includes:
- Source code shown in the video
- Requirements and dependencies
- Instructions for running the code

## Getting Started

1. Navigate to the folder for the video you're interested in
2. Follow the README instructions in that folder
3. Make sure you have the required dependencies installed (usually listed in `pyproject.toml` or `requirements.txt`)
